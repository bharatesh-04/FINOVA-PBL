# 🗄️ Connecting to Render PostgreSQL Database

## Complete Step-by-Step Guide

---

## **Option A: Manual Setup (Recommended for First-Time)**

### Step 1: Create PostgreSQL Database on Render
1. Go to https://render.com/dashboard
2. Click **"New +" → "PostgreSQL"**
3. Fill the form:
   ```
   Name:       finance-tracker-db
   Database:   finance_tracker
   User:       postgres
   Region:     ohio (or your closest region)
   Plan:       Free
   ```
4. Click **Create Database**
5. Wait 2-3 minutes for initialization

### Step 2: Get Connection String
1. Go to your PostgreSQL database page
2. Copy the **"External Database URL"**:
   ```
   postgresql://user:password@hostname:5432/finance_tracker
   ```
3. **Save this carefully** - you'll use it next

### Step 3: Add to Your Web Service
1. Go to your **web service** (finance-tracker-api)
2. Go to **Settings → Environment Variables**
3. Add a new environment variable:
   - **Key**: `DATABASE_URL`
   - **Value**: Paste the connection string from Step 2
4. Click **Save**

### Step 4: Deploy
1. Go to **Deployments**
2. Click **Deploy latest commit** (or manually redeploy)
3. Wait for build to complete (3-5 minutes)
4. Check logs for successful database connection

### If You Want Render to Create DB Automatically

1. **Update render.yaml** (already done ✓)
2. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "Add PostgreSQL database configuration to render.yaml"
   git push origin main
   ```
3. **Go to Render.com:**
   - Click **"New +" → "Blueprint"**
   - Select your GitHub repo
   - Render will automatically create both web service AND database
   - Database connection string automatically linked

## **Testing Your Database Connection**

### Locally
1. **Get your PostgreSQL connection string from Render:**
   - Format: `postgresql://username:password@hostname:5432/dbname`

2. **Create `.env` file in `backend/` directory:**
   ```env
   DEBUG=false
   DATABASE_URL=postgresql://username:password@hostname:5432/dbname
   SECRET_KEY=your-secret-key-min-32-chars
   ```

3. **Install psycopg2:**
   ```bash
   cd backend
   pip install psycopg2-binary
   ```

4. **Test connection:**
   ```bash
   python -c "from app.database import engine; print(engine.execute('SELECT 1'))"
   ```
   Should see: `SELECT 1` without errors ✓

## **Troubleshooting**

### Error: "could not translate host name"
- **Cause**: Connection string has wrong hostname
- **Fix**: Copy the entire External Database URL from Render again

### Error: "FATAL: password authentication failed"
- **Cause**: Wrong password in connection string
- **Fix**: Check the database credentials on Render

### Error: "database does not exist"
- **Cause**: Database name in connection string doesn't match
- **Fix**: Use the exact database name shown in Render dashboard

### Error: "could not connect to server"
- **Cause**: Database not yet initialized
- **Fix**: Wait 2-3 minutes and try again

### Error: "ssl error: CERTIFICATE_VERIFY_FAILED"
- **Cause**: SSL certificate issue
- **Fix**: Add `?sslmode=require` to connection string:
  ```
  postgresql://user:password@hostname:5432/dbname?sslmode=require
  ```
